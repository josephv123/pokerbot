# Poker Bot Research & Implementation Notes

## Current Performance (2025-11-25)
- **Overall training set: 68.0%** (up from 66.3% baseline)
- **vs John3: 37%** (up from 25% baseline)

## What Worked

### 1. Adaptation Detection with Rolling Window
- Track opponent's fold decisions in a rolling window (last 40 decisions)
- Store early baseline fold rate after 30 hands
- If drift > 0.20 from baseline, switch to 'balanced' mode
- This helps against opponents who adapt their strategy mid-game

### 2. Bet-Card-Mean Adjustment
- Track average card strength when opponent bets at showdown
- If opponent bets with weak hands (mean < 0.55): call 10% more
- If opponent only bets strong hands (mean > 0.75): call 10% less
- Requires 10+ showdown samples

### 3. Original Aggressive Default Strategy
- bet_mult: 5 (5x pot bets)
- bluff_mult: 2.5 (more bluffs than GTO)
- value_mult: 1.10 (wider value betting)
- call_mult: 1.15 (tighter calls)
- This works well because ~70% of training opponents are "folders"

### 4. Strategy Mode Switching (Original)
- folder (fold_rate > 0.55): aggressive mode
- caller (fold_rate < 0.30): tight mode (no bluffs)
- aggressor (raise_rate > 0.30): trapping mode
- balanced: standard GTO-ish play

## What Didn't Work

### 1. Soft Clustering / Blended Strategies
- Tried k-means clustering with 5 archetypes and blending strategies by probability
- Result: 51-58% win rate (worse than baseline)
- Problem: Averaging dilutes exploitation, GTO cap too restrictive

### 2. Lower Detection Threshold (15 → 10 bets)
- Tried faster opponent classification
- Result: Slight regression in performance
- Problem: Not enough data leads to misclassification

### 3. Aggression-Based Detection (bet-when-checked-to)
- Tried using high aggression (>0.60) to trigger trapping mode
- Result: 60% win rate (significant drop)
- Problem: False positives - many folders also bet when checked to

### 4. Lower Exploitation Cap
- Tried 30% cap on deviation from GTO baseline
- Result: Hurt performance vs folders
- Problem: Need aggressive exploitation to beat high-fold opponents

## Implementation Summary

The final implementation uses:
1. Original aggressive default strategy (proven to work)
2. Opponent type detection after 15 bets
3. Adaptation detection via rolling window drift
4. Bet-card-mean based calling adjustment
5. AllIn detection for maniac opponents

Key files modified:
- pokerplayer.py: Added rolling window tracking, bet_card_mean adjustment, adaptation detection
- analyze_opponents.py: Enhanced to extract 5D features and run k-means clustering
